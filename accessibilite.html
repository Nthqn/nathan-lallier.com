Déclaration d'Accessibilité

Nathan LALLIER s'engage à rendre son site internet accessible conformément à l'article 47 de la loi n° 2005-102 du 11 février 2005.

1

État de conformité

Le site nathan-lallier.com est en conformité partielle avec le Référentiel Général d'Amélioration de l'Accessibilité (RGAA) version 4.1.

Conformité partielle RGAA 4.1

Nous nous efforçons continuellement d'améliorer l'accessibilité de ce site pour garantir une expérience inclusive à tous les utilisateurs.

2

Fonctionnalités d'accessibilité

Ce site intègre les fonctionnalités d'accessibilité suivantes :

Contraste élevé Couleurs choisies pour assurer une bonne lisibilité
HTML sémantique Structure logique pour les lecteurs d'écran
Textes alternatifs Images décrites pour les technologies d'assistance
Design responsive Adapté à tous les appareils et tailles d'écran
Tailles de police Textes lisibles et redimensionnables
Navigation clavier Site entièrement navigable au clavier
3

Contenus non accessibles

Certains contenus peuvent présenter des limitations d'accessibilité :

  • Certains documents PDF peuvent ne pas être entièrement accessibles
  • Certaines animations peuvent ne pas respecter les préférences de mouvement réduit
  • Certains contenus tiers (vidéos intégrées, widgets) peuvent ne pas être totalement accessibles

Nous travaillons activement à corriger ces points pour améliorer l'accessibilité globale du site.

4

Technologies utilisées

L'accessibilité de ce site repose sur les technologies suivantes :

  • HTML5
  • CSS3
  • JavaScript
  • WAI-ARIA (Web Accessibility Initiative - Accessible Rich Internet Applications)

Ces technologies sont compatibles avec les navigateurs et les technologies d'assistance les plus courants.

5

Retour d'information et contact

Si vous rencontrez des difficultés d'accessibilité sur ce site ou si vous souhaitez signaler un problème, n'hésitez pas à me contacter.

Je m'engage à vous répondre dans les meilleurs délais et à rechercher une solution adaptée à votre situation.
